# Contributing

Contributions are welcome through focused issues and pull requests.

Before proposing a change:

1. Explain the invariant or use case it serves.
2. Keep renderer, network, and projection policy outside the core.
3. Add deterministic tests for new behavior and edge cases.
4. Run `npm run check`.

Do not submit code copied from another implementation. If a change is based on
an external work, identify it and confirm that its license is compatible
before opening the pull request.
